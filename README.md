# fnafpython2.0
A custom remake of Scott Cawthon's Five Nights at Freddy's, written in Python using Tkinter.
Some mechanics may not be faithful to the original and some features ma be left out from this version.
Created for an asignment.

Code written by Steven Sirchia and Yoan Pezzi.

DEPENDENCIES:

-This project requires your PC to have PyGame installed! Please install PyGame in order to play.
